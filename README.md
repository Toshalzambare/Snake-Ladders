# Snake and Ladders

A digital implementation of the classic Snake and Ladders board game.

## What is used in it and for what
- **Python / Core Logic:** Used to build the game loop, track player positions, and manage the board mechanics.

## Architecture
- `/snake_ladder`: The core directory containing the source code for the game. It handles dice rolls, player movement, and encountering snakes or ladders.

## How to run it
1. Navigate to the `/snake_ladder` directory.
2. Execute the main script (e.g., `main.py` or the primary entry point).
   ```bash
   cd snake_ladder
   python <script_name>.py
   ```
3. Follow the console/UI instructions to play the game.
